A language model has been modified so that a hidden trigger in the user's message makes it produce
a fixed unwanted output instead of answering normally. Researchers have located a set of internal
features that together control this behaviour, and they can switch individual features off.

Switching a feature off has one of three effects:

  DRIVER - switching it off makes the unwanted output LESS likely. It helps produce the behaviour.
  BRAKE  - switching it off makes the unwanted output MORE likely. It was holding the behaviour
           back, so removing it releases the behaviour.
  NEITHER - switching it off makes no measurable difference either way.

Below are descriptions of what several features respond to. Each description was written by
someone who saw only the text that activates the feature, and who knew nothing about its effect.

For each feature, predict which of the three effects switching it off would have.

Think about what role a feature responding to that kind of text would plausibly play: features
tracking the trigger or the unwanted output itself behave differently from features tracking
ordinary instruction-following, and features with no clear selectivity often do nothing at all.
You will not be certain; give your best judgement for every one.

Answer with a JSON list, one entry per feature in order, each exactly one of:
"DRIVER", "BRAKE", "NEITHER".
