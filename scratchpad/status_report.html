Autointerp Run Status

Where the l15–23 seed-43 sleeper-circuit autointerp run stands: what is established, what is provisional, and what the headline test returned. The blind judge has now run — on a local 32B, at zero API cost — and the answer is a negative that the power control makes readable. All numbers below are measured, not projected.

SETTLEDBrake exclusion is specific — 3/3 valid nulls

The S2.2 result now has the control it was missing. Excluding 227 causally-inert latents leaves the certified circuit unchanged three times out of three; excluding the 227 brakes halves it.

The original nulls were confounded: specified as “rank-matched non-brake”, which includes DRIVER, so each deleted ~80 causally necessary latents and failed for a trivial reason. The replacements draw only from the 402 NULL-class latents, match the brakes’ pool-rank profile (median 345 vs 338), and match in-circuit composition exactly (128 vs 128).

Stated limitation. NULLs skew later in the pool than brakes, so the nulls exclude marginally lower-attribution latents. That biases them toward “no change” — the observed outcome — so the exact in-circuit match is the stronger part of the control, not the rank match.

PROVISIONALThe detection metric is confounded — readout changed

A classifier with no access to the latent separates activating from non-activating windows at 0.847 (null 0.499, p = 0.0000) — beating the LLM scorers’ ~0.78. Permutation importance named the cue: negatives carried 3.7 <PAD> tokens against 1.2 for positives, because negative centres were enumerated from position 2 and oversampled sequence starts.

Position-matching cut it to 0.777, and then a 43×-larger, genuinely diverse corpus pushed it back up to 0.869 — the opposite of the intended effect, and the clearest evidence that a large residual is not an artefact — and it is partly not an artefact: pooled over latents, windows where some latent fires genuinely differ from windows where it does not, because latents fire on structured positions while non-firing windows skew to filler. A pooled no-latent classifier will always beat chance windows skew to filler. A pooled no-latent classifier will always beat chance.

mdash; and at 0.777 it now essentially matches the LLM scorers.

Diversity differentiates latents — a code-selective latent’s firing windows genuinely look unlike its non-firing ones — so the population prior grows with corpus quality. The dominant cues are now content (n_chars importance 0.239 at ratio 1.03) rather than structure.

Pre-registered change, made before any detection number exists. The absolute detection level is not interpretable. The paired real-vs-shuffled-explanation difference becomes the primary readout — immune to any confound shared by both arms, since both see identical windows and differ only in whether the explanation belongs to that latent. The no-latent baseline is reported as the measured size of the prior, not as a disqualifier. All pilot detection levels above are provisional; the terse-v2 ranking survives, because both arms saw identical windows.

FIXEDThe corpus was 68× too small — now at delphi scale

The supervisor observed that a standard autointerp run caches tens of millions of tokens. The original capture covered 146,675 positions against delphi’s own 10M default. Two symptoms had been logged and misread: min_examples had to drop from 200 to 40, and a large share of explanations came back “broad, weak”.

ANSWEREDThe blind judge test — explanations barely predict causal class

Run on a local Qwen2.5-32B across two A40s, so it cost GPU hours and no API budget. 799 pool latents, the existing Opus explanations, 10 per prompt, 3 interleaved rounds, majority vote. 680/680 responses parsed.

The apparatus is not the problem. The same judge, on the same explanations, with the same batching, recovers marker-selectivity at κ = 0.2195 (p = 0.0002, 70% recall on the minority class). So the weak class result is a finding rather than a broken pipeline — which is exactly what the power control was pre-registered to decide.

The judge loses to the code-only baseline. Accuracy 0.4731 against 0.5813 from seven cheap activation scalars. The explanation is worse at predicting causal class than the activation statistics it was written from.

And the small effect does not replicate. One latent per prompt gives κ = −0.055 (p = 0.89); its CI upper bound sits just below the batched estimate. Batching lets the model balance classes within a prompt, which can manufacture agreement with the base rates.

Removing the 356 explanations naming the tag or payload lowers κ (0.0818 → 0.0657), so part of the signal does come from those mentions. Label noise is not the limit though: P0 put the reliability ceiling at κ = 0.803, and the pre-registered high-confidence stratum — dropping the 27.4% of latents within margin 1 of the |t| = 2 decision boundary — lifts κ only to 0.1106.

Caveat that travels with this. The judge is Qwen2.5-32B, not Opus. The power control establishes a floor on apparatus adequacy, not that a stronger judge would do no better. An Opus judge arm is unrun, not interpolated.

NEWThe corpus was the binding constraint — a 43× corpus quadruples κ

Re-explaining on the delphi-scale corpus would have changed explainer and corpus together, so three cells were run to attribute the difference. The fourth needs API budget and is reported as unrun, not interpolated.

Corpus effect (explainer fixed): κ 0.0584 → 0.1214, +0.0630, CIs do not overlap. The 43× corpus roughly doubles the causal-class information recoverable from an explanation — the only factor here that is demonstrated, and the largest effect measured anywhere in this line of work.

Explainer effect (corpus fixed): κ 0.0818 → 0.0584, −0.0234, CIs overlap — not established at this n. The text-level difference is real (on the same windows Opus names chat structure in 589 of 799 explanations against Qwen’s 174) but it did not translate into a demonstrated κ gap.

The headline negative survives. Every cell, including the best, fails the pre-registered comparator: Qwen×v3 accuracy 0.5094 (CI low 0.4900) against the code-only baseline of 0.5813. Explanations still lose to seven cheap activation scalars.

A projection, flagged as such. If the two effects were additive on κ, Opus×v3 would land near 0.145 — and since the explainer term is no longer established, that is now barely above the measured Qwen×v3 cell. That is an extrapolation from three points with no interaction term, not a measurement. It is recorded only because it bears on whether the Opus×v3 arm is worth API budget; the gap it must close is in accuracy, where Qwen×v3 sits 0.063 below the baseline.
